# Narration script

Derived from `record/out/timeline.v2.json` by `npm run record:narrate`, so it cannot drift from the
captions on screen: one spoken line per caption, at the caption's own cue time. Do not edit this file.
Change a caption in `record/player/edit.v2.mjs`, re-render, and re-run the script.

**To record it yourself.** One file per line, named by the index below, into `record/narration/`:
`00.wav`, `01.wav`, and so on (`.aiff`, `.m4a` and `.mp3` also work). Leave out any line you do not
want to read and it is synthesised instead. Then:

```sh
NARRATE_VOICE=human npm run record:narrate
```

The **window** column is how long that caption is on screen. A take longer than its window still
works, it just overlaps the next line, so read to the window where you can.
